# Промпт: Визуальный интерфейс — Сайт-визитка с QR-кодом и реферальной системой

> Связанные документы: [PRD](../prd/README.md) | [Отчёт по полноте PRD](../prd/PRD_completeness_report.md) | [Архитектура](../architecture/README.md) | [Инфраструктура](../infrastructure/README.md) | [BDD](../bdd/README.md)

## Контекст

Сайт-визитка для сбора заявок с офлайн-носителей (QR-коды на визитках/рекламе) и партнёрских каналов. Пользователь сканирует QR → попадает на лендинг → выбирает услугу → оставляет заявку. Параллельно партнёры получают реферальные ссылки и привлекают клиентов.

## Стек

- Vue 3 (Composition API, `<script setup>`)
- Tailwind CSS
- Mobile-first (QR сканируют с телефона)

## Страницы для реализации

### 1. Лендинг (публичная часть) — `/`

Единая страница, скроллинг-based:

**Hero-секция:**
- Логотип (центр)
- Краткое описание компании (1–2 предложения)
- Фон: чистый, минималистичный, brand-цвета

**Секция «Услуги»:**
- Сетка 3–5 карточек услуг (на мобилке — вертикальный стек)
- Каждая карточка: иконка, название услуги, описание (1 строка), цена (опционально)
- Карточка кликабельна → подскролливает к форме и выбирает услугу

**Секция «Заявка» (CTA + форма):**
- Заголовок: «Оставьте заявку»
- Поля формы:
  - Имя (текстовое поле, обязательное)
  - Телефон (input type="tel", обязательное, маска ввода +7 (XXX) XXX-XX-XX)
  - Выбор услуги (выпадающий список или радиокнопки, привязан к карточкам выше)
- Чекбокс: «Я согласен на обработку персональных данных» (обязательный, со ссылкой на политику)
- Кнопка «Отправить заявку» — крупная, контрастная,занимает всю ширину на мобилке
- Под кнопкой: мелкий текст «Нажимая «Отправить», вы соглашаетесь с политикой конфиденциальности»

**Состояния формы:**
- **Idle:** поля пустые, кнопка активна
- **Loading:** кнопка показывает спиннер, поля заблокированы
- **Success:** форма скрывается, показывается блок «Спасибо! Ваша заявка принята. Мы свяжемся с вами в ближайшее время.» с иконкой галочки
- **Error:** красная подпись под формой «Произошла ошибка. Попробуйте ещё раз.» + кнопка «Повторить»

**Поведение:**
- При переходе по `/?ref=TOKEN` — токен сохраняется в cookie (30 дней, path=/, SameSite=Lax)
- При выборе услуги из карточек — форма автоматически прокручивается и услуга выбирается

### 2. Админ-панель — `/admin`

**Вход:**
- Страница логина: поле email, поле пароль, кнопка «Войти»
- Ошибка: «Неверный email или пароль»

**Дашборд (главная):**
- Верхняя панель: общее число заявок, заявки за сегодня, число партнёров
- Таблица заявок с колонками:
  - Дата
  - Имя
  - Телефон
  - Услуга
  - Источник (QR / Партнёр: имя)
  - Статус (NEW / CONTACTED / CONVERTED / REJECTED)
- Фильтры над таблицей: по дате (диапазон), по услуге, по партнёру, по статусу
- Кнопка «Экспорт в CSV»

**Управление услугами — `/admin/services`:**
- Список услуг с полями: название, описание, цена, статус (активна/скрыта)
- Кнопки: «Добавить услугу», «Редактировать», «Скрыть/Показать»

**Управление партнёрами — `/admin/partners`:**
- Список партнёров: имя, email, статус (активен/заблокирован), реферальная ссылка
- Кнопки: «Добавить партнёра», «Заблокировать/Разблокировать», «Копировать ссылку»
- У каждого партнёра: число переходов, число заявок, конверсия

## Требования к дизайну

### Mobile-first
- Все элементы — крупные touch-targets (минимум 44×44 px)
- Форма — не более 3 полей (имя, телефон, услуга)
- Телефон — нативная клавиатура (`type="tel"`)
- CTA-кнопка —занимает всю ширину на мобилке
- Адаптация от 320px до 1440px

### Визуал
- Чистый, минималистичный стиль
- 1–2 brand-цвета + оттенки серого
- Консистентные отступы (multiples of 4px)
- Круглые углы (rounded-lg или rounded-xl)
- Тени карточек: subtle (shadow-sm или shadow-md)

### Состояния
- Loading: спиннер на кнопке + заблокированные поля
- Success: анимация появления галочки
- Error: красные рамки на полях + текст ошибки под полем
- Пустое состояние в админке: «Заявок пока нет»

### Доступность
- Все поля формы имеют `<label>` (визуально скрытый, но доступный для screen reader)
- Кнопки имеют текст (не только иконки)
- Цвет не единственный индикатор статуса (иконка + текст)

## Не реализовывать (V2)

- Личный кабинет партнёра
- Онлайн-оплата
- Интеграция с CRM
