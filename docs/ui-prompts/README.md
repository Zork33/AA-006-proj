# Промпт: Визуальный интерфейс — Сайт-визитка с QR-кодом и реферальной системой

> Связанные документы: [PRD](../prd/README.md) | [Отчёт по полноте PRD](../prd/PRD_completeness_report.md) | [Архитектура](../architecture/README.md) | [Инфраструктура](../infrastructure/README.md) | [План развития](../roadmap/README.md) | [BDD](../bdd/README.md)

## Контекст

Сайт-визитка для сбора заявок с офлайн-носителей (QR-коды на визитках/рекламе) и партнёрских каналов. Пользователь сканирует QR → попадает на лендинг → выбирает услугу → оставляет заявку. Параллельно партнёры получают реферальные ссылки и привлекают клиентов.

Бренд: **ВСЯК** — универсальный справочник услуг для новоселов.

## Стек

- Svelte (SvelteKit или Vite + Svelte)
- UnoCSS (Tailwind-совместимый синтаксис через `@unocss/preset-wind`)
- Mobile-first (QR сканируют с телефона)

## Дизайн-система

### Логотип

Чистый современный вортмарк **«ВСЯК»** — мягкий скруглённыйsans-serif, буквы тёмного графитового цвета, последняя буква **«К»** — мягкий голубой (#A5C4E8). Центрирован в верхней части страницы. Элегантный и минималистичный.

### Палитра цветов (Soft Sage & Cream)

| Роль | Цвет | HEX |
|---|---|---|
| Primary | Soft sage green | `#6B9B7A` |
| Primary hover | Darker sage | `#5A8A69` |
| Background | Warm cream | `#F9F7F2` |
| Surface / cards | Pure white | `#FFFFFF` |
| Text primary | Warm dark gray | `#2D2A26` |
| Text secondary | Muted warm gray | `#7A736A` |
| Borders | Soft warm gray | `#E8E4DC` |
| Success | Soft mint | `#81B29A` |

### Типографика

- Заголовки: системный sans-serif (Inter / San Francisco)
- Основной текст: 16px, line-height 1.5
- Заголовки секций: 24–32px, font-weight 600
- Мелкий текст: 12–14px

### Отступы и размеры

- Базовый отступ: 8px (multiples of 4px)
- Border-radius: 12px (карточки), 8px (инпуты), 24px (кнопки)
- Тени: `0 2px 8px rgba(0,0,0,0.06)` (карточки), `0 4px 16px rgba(0,0,0,0.08)` (hover)

## Страницы для реализации

### 1. Лендинг (публичная часть) — `/`

Единая страница, скроллинг-based. Фон: warm cream (#F9F7F2).

**Hero-секция:**
- Логотип «ВСЯК» (центр, крупный)
- Краткое описание: «Быстро найдите мастера для вашего дома» (или similar)
- Много whitespace, чистое пространство

**Секция «Наши услуги»:**
- Заголовок: «Наши услуги»
- 3 карточки в вертикальном стеке (на мобилке)
- Каждая карточка: белый фон,soft rounded corners (12px), subtle shadow
- Иконка (soft sage green), название услуги, короткое описание
- Карточка кликабельна → подскролливает к форме и выбирает услугу

**Секция «Оставьте заявку» (CTA + форма):**
- Заголовок: «Оставьте заявку»
- Поля формы (soft rounded corners, warm gray borders):
  - Имя (текстовое поле, обязательное)
  - Телефон (input type="tel", обязательное, маска +7 (XXX) XXX-XX-XX)
  - Выбор услуги (выпадающий список, привязан к карточкам выше)
- Чекбокс: «Я согласен на обработку персональных данных» (обязательный)
- Кнопка «Отправить заявку» — large, full-width, soft sage green (#6B9B7A), white text, border-radius 24px
- Под кнопкой: мелкий текст «Нажимая «Отправить», вы соглашаетесь с политикой конфиденциальности»

**Состояния формы:**
- **Idle:** поля пустые, кнопка активна
- **Loading:** кнопка показывает спиннер, поля заблокированы
- **Success:** форма скрывается, показывается блок «Спасибо! Ваша заявка принята.» с иконкой галочки (soft mint #81B29A)
- **Error:** красная подпись под формой + кнопка «Повторить»

**Поведение:**
- При переходе по `/?ref=TOKEN` — токен сохраняется в cookie (30 дней)
- При выборе услуги из карточек — форма автоматически прокручивается

### 2. Форма отзыва — `/feedback`

- Заголовок: «Оцените качество услуги»
- Рейтинг: 5 звёзд (кликабельные, soft sage green при выборе)
- Комментарий (опционально, textarea)
- Кнопка «Отправить отзыв»
- Состояния: Loading, Success («Спасибо за отзыв!»), Error

### 3. Авторизация

**Вход — `/auth/login`:**
- Логотип «ВСЯК» (сверху)
- Поля: email, пароль
- Кнопка «Войти» (soft sage green)
- Ссылки: «Забыли пароль?», «Регистрация»

**Регистрация — `/auth/register`:**
- Поля: имя, email, пароль, подтверждение пароля
- Кнопка «Зарегистрироваться»

**Сброс пароля — `/auth/reset`:**
- Поле: email
- Кнопка «Отправить ссылку»

### 4. Админ-панель — `/admin`

**Дашборд (главная):**
- Верхняя панель: общее число заявок, заявки за сегодня, число партнёров
- Таблица заявок: дата, имя, телефон, услуга, источник, статус, рейтинг клиента
- Фильтры: по дате, услуге, партнёру, статусу
- Кнопка «Экспорт в CSV»

**Управление услугами — `/admin/services`:**
- Список услуг: название, описание, цена, статус
- Кнопки: «Добавить», «Редактировать», «Скрыть/Показать»

**Управление партнёрами — `/admin/partners`:**
- Список: имя, email, статус, рейтинг, approval_status, регион
- Кнопки: «Добавить», «Одобрить/Отклонить», «Заблокировать», «Копировать ссылку»
- Детали: `/admin/partners/:id` — полная статистика, рейтинг, история

**Управление админами (суперадмин) — `/admin/admins`:**
- Список админов: имя, email, роль, регион
- Кнопка «Добавить админа»

### 5. Личный кабинет партнёра — `/partner`

**Дашборд:**
- Число заявок, конверсия, рейтинг
- Список последних заявок

**Реферальная ссылка — `/partner/referral`:**
- Ссылка: `site.com/?ref=TOKEN`
- Промо-код
- Кнопка «Копировать»

**Приглашённые — `/partner/invites`:**
- Список приглашённых партнёров: имя, дата регистрации, статус

## Требования к дизайну

### Mobile-first
- Все элементы — крупные touch-targets (минимум 44×44 px)
- Форма — не более 3 полей (имя, телефон, услуга)
- Телефон — нативная клавиатура (`type="tel"`)
- CTA-кнопка — занимает всю ширину на мобилке
- Адаптация от 320px до 1440px

### Визуал
- Clean, warm, premium, много soft whitespace
- Мягкие тени, скруглённые углы, modern and friendly
- Без резких контрастов (no harsh contrasts)
- Мягкое естественное освещение (soft natural lighting)
- Cream background (#F9F7F2)

### Состояния
- Loading: спиннер на кнопке + заблокированные поля
- Success: анимация появления галочки
- Error: красные рамки на полях + текст ошибки под полем
- Пустое состояние: «Заявок пока нет»
- Партнёр без апровала: серый бейдж «На модерации»

### Доступность
- Все поля формы имеют `<label>` (визуально скрытый, доступный для screen reader)
- Кнопки имеют текст (не только иконки)
- Цвет не единственный индикатор статуса (иконка + текст)
