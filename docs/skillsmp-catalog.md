## Рекомендации по установке

Для наиболее эффективной работы рекомендуется установить следующие скиллы:

1. **drizzle-orm-expert** — для работы с ORM и миграциями
2. **nodejs-backend-patterns** — для Fastify паттернов
3. **senior-backend** — для API проектирования и PostgreSQL
4. **security-review** — перед выходом в продакшн
5. **sveltekit** — для фронтенд-компоновки
