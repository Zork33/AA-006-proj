## Решения по дизайну и контенту

### Дизайн

- Стиль: минималистичный, чистый
- Цвета: 1–2 brand-цвета + оттенки серого (пока не определены)
- Шрифт: системный (Inter / San Francisco) или Google Fonts
- Логотип: текстовый (название компании) до получения графического

### Тексты (черновики)

**Hero-секция:**
```
[Название компании]
Быстро оставьте заявку — мы свяжемся с вами
```

**Политика конфиденциальности (шаблон согласия):**
```
Я даю согласие на обработку персональных данных в соответствии с
политикой конфиденциальности.
```

**Описание компании (placeholder):**
```
[Опишите вашу компанию в 1–2 предложениях]
```
