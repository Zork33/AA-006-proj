## Фаза 1: Закрытие бизнес-вопросов (до кода)

Ответы на 4 вопроса из PRD:

| # | Вопрос | Важность | Статус |
|---|---|---|---|
| 1 | Какие услуги и сколько? Фиксированный список? | Высокая | Решено |
| 2 | Нужна ли цена услуги на лендинге? | Средняя | Ожидает ответа |
| 3 | Какие данные кроме имени и телефона? (email, город?) | Средняя | Решено |
| 4 | Один QR или несколько кампаний с разными UTM? | Средняя | Решено |
| 5 | Какое осмысленное название проекта/бренда? | Высокая | Варианты обсуждены |

**Решения:**
- Услуги: фиксированный список на старте — недвижимость, сантехника, кондиционирование, окна, двери, электрика, клиники. Партнёры — монтажники всего.
- Логотип/цвета: нужна помощь с дизайном
- Тексты (Hero, политика): нужны шаблоны/примеры
- Стек фронта: Svelte + UnoCSS (зафиксировано)
- Данные клиента: имя, телефон, email, город (обязательные) + мессенджеры (опционально)
- QR-код: один QR → один лендинг. Реферальная ссылка `?ref=TOKEN` для каждого партнёра. Возможность масштабирования на несколько лендингов по регионам.
- Название: варианты обсуждены (Source, Lido, Privo, Линка, ВСЯК), решение не принято. Рабочее название: Proj.

## Фаза 4: Разработка (поэтапный план)

**Стек:** Node.js + Fastify + TypeScript + PostgreSQL + Svelte + UnoCSS
**ORM:** Drizzle (ahl)
**Контейнеризация:** Docker Compose (PostgreSQL 15)

### Этап 0: Каркас проекта (0.5 дня)

- `docker-compose.yml`: PostgreSQL 15, порт 5432, healthcheck
- `db/init.sql`: миграции + seed-скрипт (дефолтный список услуг)
- Backend: Fastify + `@fastify/cors`, `@fastify/env`
- Структура: `packages/backend/`, `packages/frontend/`
- `tsconfig.base.json`, `package.json` (workspace root)

### Этап 1: API заявок — ядро (1–2 дня)

| Эндпоинт | Описание |
|---|---|
| `GET /api/services` | Список активных услуг |
| `POST /api/leads` | Создание заявки (name, phone, email, city, service_id) |

- Валидация полей (zod)
- Дедупликация: телефон + услуга за 24ч → 409
- Формирование номера: `QR-0001`

### Этап 2: Лендинг + форма (1–2 дня)

- Svelte + Vite + UnoCSS
- Hero-секция, карточки услуг, форма
- Mobile-first адаптив
- POST на `/api/leads`, показ «Спасибо»

### Этап 3: Реферальная система (1 день)

| Эндпоинт | Описание |
|---|---|
| `POST /api/admin/partners` | Создание партнёра (admin) |
| `GET /api/admin/partners` | Список партнёров |

- Реферальная ссылка: `site.com/?ref=TOKEN`
- Cookie: `ref=TOKEN` (30 дней, SameSite=Lax)
- First-touch атрибуция

### Этап 4: Админ-панель (1–2 дня)

**Админ-интерфейс (для нас):**

| Эндпоинт | Описание |
|---|---|
| `GET /api/admin/leads` | Все заявки (фильтры: партнёр, дата, статус) |
| `PATCH /api/admin/leads/:id` | Смена статуса |
| `GET /api/admin/export` | Экспорт CSV |
| `GET /api/admin/partners` | Список партнёров со статистикой |

- Страница `/admin` (Svelte)
- JWT-авторизация (один админ)

**Интерфейс партнёра (для партнёров):**

| Эндпоинт | Описание |
|---|---|
| `GET /api/partner/dashboard` | Дашборд: заявки, конверсия, статистика |
| `GET /api/partner/referral` | Реферальная ссылка и промо-код |
| `GET /api/partner/invites` | Список приглашённых партнёров |

- Страница `/partner` (Svelte)
- Вход по email + код из письма (magic link) или по паролю
- Партнёр видит только свои данные

### Этап 5: Уведомления MAX-бот (0.5 дня)

- После `POST /api/leads` → вызов MAX Bot API
- Формат: имя, телефон, услуга, источник

### Этап 6: Партнёрская рефералка (0.5 дня)

| Эндпоинт | Описание |
|---|---|
| `POST /api/partners/register` | Регистрация партнёра с промо-кодом |

- Поле `referrer_id` в таблице `partners`

### Этап 7: Безопасность и полировка (1 день)

- Rate limiting: 10 req/min на `POST /api/leads`
- Honeypot-поле против спама
- CSRF-токены
- HTTPS (Let's Encrypt)
- Логирование ошибок

### Этап 8: Деплой (0.5 дня)

- Selectel VPS: Ubuntu 22.04, Node.js 20+, PM2
- Nginx reverse proxy + SSL
- MAX-бот на dev.max.ru

## Решения по дизайну и контенту

### Дизайн

- Стиль: минималистичный, чистый
- Цвета: 1–2 brand-цвета + оттенки серого (пока не определены)
- Шрифт: системный (Inter / San Francisco) или Google Fonts
- Логотип: текстовый (название компании) до получения графического

### Тексты (черновики)

**Hero-секция:**
```
[Название компании]
Быстро оставьте заявку — мы свяжемся с вами
```

**Политика конфиденциальности (шаблон согласия):**
```
Я даю согласие на обработку персональных данных в соответствии с
политикой конфиденциальности.
```

**Описание компании (placeholder):**
```
[Опишите вашу компанию в 1–2 предложениях]
```
